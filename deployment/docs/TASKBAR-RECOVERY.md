# 展示期间的任务栏

三屏启动确认后，启动脚本直接隐藏本桌面的主任务栏和副屏任务栏。
STOP SHOW 完成清理后恢复；Ctrl+Shift+S 完成清理后恢复并沿用原有关机流程。
启动脚本捕获异常退出时也会尝试恢复。隐藏或恢复失败仅警告，不中断展演或关机流程。
不修改 Windows 自动隐藏设置、屏幕映射、窗口大小或 JanVim 产品文件。

如果启动脚本被强制结束，任务栏可能暂时保持隐藏。双击桌面“恢复任务栏”，
或按 Win+R 执行：

```powershell
pwsh -NoProfile -File "D:\github\JanVim-Exhibition-Deploy\operator\Restore-Taskbar.ps1"
```

恢复入口不启动、不停止展示，也不需要旧运行会话。任务栏恢复后仍遵循原有自动隐藏设置。
此方案没有新增常驻进程；Explorer 在展演中重启或自行重新显示任务栏仍需现场确认。

冷启动验收：开机后不点击 JanVim，确认三屏就绪后任务栏消失；
点击 STOP SHOW，确认任务栏恢复。自动测试和短暂隐藏探测不能替代这一步。
