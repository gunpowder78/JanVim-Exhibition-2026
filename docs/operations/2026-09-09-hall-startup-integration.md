用户 08:36:05 UTC 保存的角色为：JanVim `(0,0)`，Narrative `(1920,0)`，
《见山》`(-1920,0)`，各为 1920×1080、100% 缩放、无旋转。

解析器在全部已分配及未分配显示器数量、位置、分辨率、缩放和旋转唯一匹配时按位置
重绑定角色，记录 `saved-geometry`。不仅覆盖全新 ID，也覆盖旧 ID 被系统重新分配。
任务栏工作区和设备名称不参与稳定匹配。布局不匹配时继续使用既有 ID 匹配/默认排序规则。
用户现场配置不被运行解析结果覆盖；物理换线或调整桌面布局后仍需现场确认。

允许原生最大化边框超出工作区的正常差异。历史 G2 和未要求最大化的调用不改行为。

## 关机

沿用全局快捷键及唯一协调器的停止边界。成功接受快捷键 Stop 后，仅在成功终态写入
`operator-stop-poweroff` 原因；普通 STOP SHOW 保留 `operator-stop`，故障不写关机请求。
既有 `controller-terminal.json` 六字段结构不变，现有启动脚本继续验证本场运行/进程身份。
部署入口等 Show 成功退出、《见山》退出、声音 clean 回执、声音进程退出和活动指针移除后，
再校验本场终态并调用 Windows `shutdown.exe /s /t 0`，无 `/f`，请求进程等待有 5 秒上限。

自动测试使用真实状态机、假时钟及进程调用边界替身，不实际关机。覆盖重启 ID 全换和复用、
布局改变、真实 Win32 最大化、错误显示器、快捷键/按钮区分、终态传递及清理失败不关机。
独立复核提出的 ID 复用问题已先复现失败并修正；完整门禁和安装结果记录在外部任务回执。

断电后的完整测试为 1,337/1,342 通过：4 项既有 5 秒超时，以及 1 项启动器测试
清理临时目录时的 Windows EBUSY。原时间限制下单独复查 376 项全部通过，另单独复查
该 EBUSY 用例通过；默认全量运行不记为全绿。npm ci、类型检查、构建、lint 均通过。
此前被断电中断的测试日志保留，不计作完成结果。

`Global\JanVimExhibitionDeployment` 互斥锁，覆盖启动校验至全场清理，获取等待为零。

内容不一致或不可验证的记录仍拒绝；不读取旧 session/control，不终止其他进程。
