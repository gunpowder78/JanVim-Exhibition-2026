## 一、确认的修订

- 撤回固定等距中点抽样。已复算 `N=102400,K=1024`，旧公式的五群样本数确为 `[1024,0,0,0,0]`。
- 接受固定种子、全局活动索引上无放回抽样；不按 GPU 分块平均分配样本，不逐帧重新随机。
- 接受独立抽样 shader、最多 8 KiB 的两浮点/样本结果、异步回读后 CPU 汇总；不修改力学 shader、不引入 Tokio、不升级 wgpu、不改 MediaPipe。
- 接受 CPU/GPU 首版固定 `vRef=4.0`，作为独立配置项启动时记录，含义仅为名义模拟运动强度。
- 下文补齐挂接、时间、积压、epoch 和 Stop 边界；原独立 OSC 试听保留，联动时由技术人员关闭重复声音源。

## 二、入口与严格帧格式

复用声音进程现有 `127.0.0.1` TCP 监听，不增加服务或固定端口。后续声音启动器生成当次私有 `flock-input.json`；由操作员明确传给《见山》，不扫描最新目录。字段集：

`version:1, active:boolean, host:"127.0.0.1", port:int[1,65535], protocol:"jianshan-flock-ndjson-v1", token:string`

只有 active=true 可挂接。token 是 **64 个**小写十六进制字符（32 随机字节），独立于 Show 控制令牌，仅授权鸟群输入。它不能 Stop、续 Show 租约或冒充光标。回执最多 4096 字节，只读当次指定普通文件；不写日志、不复制进共享报告。

挂接：`{"version":1,"command":"attach-flock","token":... ,"sourceId":...}`。

sourceId 是每个鸟群进程创建的 **32 个**小写十六进制字符（16 随机字节），不是“32 bit”，也不是最终 OSC session。

sourceId/token 使用系统安全随机源；下文 SplitMix64 只用于可复现抽样，不得用于这些身份或凭证。

成功 ACK：`{"version":1,"ok":true,"input":"jianshan-flock-ndjson-v1"}`。

失败 ACK：`{"version":1,"ok":false,"reason":"rejected"}`，随后关闭该连接；不泄露身份或 token。畸形、超长或超时连接可直接关闭而不保证送达 ACK。所有帧 UTF-8、单行 JSON、以 LF 终止；接收允许 CRLF。ACK 最多 256 字节，不计行终止符。

长度上限不包含 CR/LF。接收器等待 LF 时，允许暂存“1024 字节数据＋一个末尾 CR”；其后只能接受 LF。ACK 的 256 字节上限采用同一规则。

- 生产端连接至完整成功 ACK 的总期限 1000 ms；服务端从 accept 到完整合法挂接帧也是 1000 ms。后台处理，不等待在绘制线程上；失败后本次入口禁用，无无限重连。
- 每个声音运行最多一个鸟群 owner，与 Show owner 分开。第一次合法挂接建立身份，即使随后断线，也不由第二连接接管；重复连接只拒绝新连接，不影响已有 Show/鸟群 owner。沿用声音监听器最多 8 条总连接的有界容量。
- 成功 ACK 后只发送下述数据帧；不逐包 ACK，不重复 token。服务端在该连接接受的能力只有鸟群输入，不能接受控制命令。

| 数据帧字段 | 严格类型/规则 |
| --- | --- |
| version / command | 整数 1 / 固定字符串 `"flock"` |
| sourceId | 与连接挂接身份逐字一致 |
| seq | 整数 1..2147483647，所有状态帧共同递增，可跳号 |
| epoch | 整数 1..2147483647，初始 1，只可保持或增加 |
| sampledAtMs | 有限 float64，范围 0..3600000 ms，含义见下一节 |
| state | `"sample"`、`"empty"`、`"unavailable"` 三选一 |
| energy / centroidX | 仅 sample 帧有这两项；有限数值 `[0,1]` |

字段不得缺失或增加，NaN/Infinity 不接受。empty/unavailable 帧**不得携带**伪造的 energy/centroidX。data 帧最多 1024 字节，不计行终止符。不发送逐鸟记录。模拟声音默认和现有光标帧格式不改。

此阶段仍遵守当次声音服务的现有有限运行时长；上限字段不是承诺全天连续声音服务，全天运行能力另验。

## 三、采样时钟、新鲜度和顺序

接收方在排入成功 ACK 前记录本地单调锚点 R；生产方收到完整合法成功 ACK 时记录本地单调零点 P。不同进程的原始时钟值不直接比较、不用 UTC 校时，也不另建时钟服务。

- GPU sample 的 sampledAtMs = 目标模拟/抽样任务提交时间减 P；CPU sample 使用本轮实际更新/采样的时间减 P。不能填回读完成、排队结束或网络发送时间。
- empty/unavailable 记录本次状态确认时间减 P。挂接前样本不发；该状态之后才完成的更旧样本直接丢弃，不能修改时间让其冒充新数据。
- 接收方的保守截止时间 `deadline = R + sampledAtMs + 500`。ACK 的传输延迟只会缩短有效期。有效年龄为 `[0,500)`；负年龄/未来时间、非有限值或 age>=500 的数据丢弃。确认延迟导致持续过期时报告并禁用入口，不自动放宽或重置锚点。
- seq 必须大于上一完整合法接纳帧，sampledAtMs 不小于上一帧，epoch 不小于上一帧；非法帧不续新鲜度。源码生命周期变化不能重置时钟或 seq。
- **收到时已老 490 ms，只剩 10 ms。** 接收时保存原 deadline，排队、IPC、转发均不得续成新的 500 ms；最终声音 sender 在发送前再次检查，风声有效目标在原 deadline 到期时开始淡出。
- seq/epoch 将溢出，或本地单调时间发生异常时，禁用本次鸟群入口，丢弃待发状态；绝不归零回绕。人工新运行重建身份。不同声音进程的声学 session 仍只由唯一 sender 管理。
- 当采样时间将超过 3,600,000 ms 时，生产端关闭连接并禁用本次鸟群入口；不得截断时间、归零或发送越界帧。见山画面继续运行，风声按断连规则淡出。

这是逻辑截止期限，不是对 Windows 调度/GPU 或 DAC 的硬实时承诺；线程暂停后的第一步必须先检查到期并丢弃旧状态。全局声音进程故障仍依赖既有 DSP 心跳淡出保护，不声称新增了硬实时系统。

## 四、双端有界队列与 epoch

默认统计/发送 10 Hz，联合入口硬上限 20 Hz；统计在途时跳过下一次，不补采历史帧。

发送端：一个后台发送器、一条正在写的编码帧、一个最新未编码状态。部分 TCP 写入不能被 reset/新 epoch 截断并拼接另一条 JSON：继续完成该帧（保留其旧身份/时间），随后仅发送最新状态；若背压超过 500 ms，关闭该鸟群输入。已经进入 TCP 的字节不能撤回，不重发失败帧。

接收端：逐条有界解析和校验，但**不逐条驱动声音**；仅保留一个最新合法状态及原 deadline，最多每 50 ms 取用一次。可用状态变化或到期可更早关闭风声，不必等下一条 packet。一次回调最多处理 64 帧/64 KiB；超出则禁用该鸟群连接，不能无限 drain 旧队列；残留未完成单帧的数据不得超过 1024 字节，仅允许另暂存第二节规定的一个末尾 CR。不合法/旧包不挤掉较新的合法目标，不续期限。

epoch 在软重置、活动鸟数变化、成员集合变化、后端切换、GPU 设备/管线重建时递增。单纯位置/速度更新不变 epoch。普通逐鸟状态变化是否改变成员集合，以活动索引所代表的鸟身份是否更换为准。

生产端清除旧 epoch 的最新待发值，并使所有旧在途 readback 失效；回读完成仍正确 unmap/释放，但不发送旧结果。数量不变时索引表可复用，成员/状态重置仍必须刷新 epoch。

接收方接受合法新 epoch 时，清除旧目标和旧待发值；此后任何旧 epoch 永远不能恢复风声。尚未知道新 epoch 时，不能声称已撤回此前合法接受的 TCP 数据。统一 Stop 优先于任何 epoch、帧解析和恢复回调。

## 五、固定无放回抽样：算法与测试向量

冻结算法名 `floyd-splitmix64-u32-v1`。这是确定性的伪随机抽样，不保证每个群落恰好等量；避免与 index%species_count 的固定步长锁相。只在活动数量变化时重新生成，不逐帧换种子。

输入整数 `N=activeCount`，`0<=N<=2147483647`；生产 K=min(N,1024)。N=0 返回空表；K=N 返回 `[0..N-1]`；否则每次生成都重置 state 为 `0x4a534e30325f7631`。

采用 [SplitMix64 作者参考实现](https://prng.di.unimi.it/splitmix64.c)的无符号 64 bit 运算（加乘模 2^64，右移为逻辑右移）：

```text
state += 0x9e3779b97f4a7c15
z = state
z = (z xor (z >> 30)) * 0xbf58476d1ce4e5b9
z = (z xor (z >> 27)) * 0x94d049bb133111eb
z = z xor (z >> 31)
r = high32(z)
```

取 `[0,b)` 均匀整数时，使用 64 bit 计算 `limit=floor(2^32/b)*b`；r>=limit 则再取 r，否则返回 r%b，避免直接取模偏差。每次最多尝试 64 次；耗尽则该次统计 unavailable，不使用有偏回退或无限循环。

Floyd 步骤：空集合 S；依次令 `j=N-K..N-1`，抽 `t=uniform(j+1)`；若 t 已在 S 中则加入 j，否则加入 t。最后升序排序，CPU/GPU 共用这一张全局索引表。算法语义可参照 [Rust rand 的索引抽样实现](https://docs.rs/rand/latest/src/rand/seq/index.rs.html)，但不依赖某版本 rand 自动选择的算法/默认 RNG，不因此引入新依赖。

本次仅在隔离计算中核验文档算例，没有向任一产品写入采样实现。测试向量如下；小 K 是算法单测参数，不是生产配置。

| N / K | 升序输出或校验 |
| --- | --- |
| 0 / 0 | `[]` |
| 5 / 5 | `[0,1,2,3,4]` |
| 11 / 3 | `[2,3,4]` |
| 20 / 7 | `[1,5,9,10,12,17,18]` |
| 102400 / 1024 | index%5 的计数 `[236,181,187,213,207]`；全部五群均有样本 |
| 200000 / 1024 | index%5 的计数 `[218,202,210,190,204]` |

大向量 SHA-256 定义：将升序索引逐个编码为 uint32 little-endian，无头、无分隔、无换行，共 4096 字节。

- N=102400：`a143246996ab90282f2f7bea1062691f78187132c55bcab209929eb098e1f252`
- N=200000：`e93c9010f82c6c2481fc402dc151a0b677a93ac05856fb81540c90d17d014da8`

上述计数证明没有旧反例的锁相，不代表统计误差为零或保证每种群大小下各群都被覆盖。后续测试需检查范围、无重复、确定性、全量退化、小集合和拒绝采样上限。

## 六、实际特征、GPU 边界与声音生命周期

取最终存储的 velocity，不先按个体限幅：`energy=clamp(mean(length(velocity))/4.0,0,1)`。CPU 是每次 update 的 position+=velocity；GPU 使用约16.6667ms名义步并带限幅时间系数，因此这里只对齐名义运动强度，不保证相同像素/秒或两后端动力学一致。独立配置 vRef=4.0 启动时冻结并写入运行证据，不随幕、鸟数、观测最大值自动变化。

`centroidX=mean(clamp(x/1000,0,1))`；统计全局活动鸟的样本，越界投影到画布边缘，回绕用本次真实状态；不做环形均值或分块均值再等权平均。空鸟群没有可定义的重心，发送 empty，不发送两个伪造数值。

独立抽样 shader 从本次计算后供绘制的活动缓冲读取，每样本输出两个 f32：速度模、投影横坐标。K<=1024 时原始回读量<=8192字节。使用独立 staging buffer，至多一笔统计在途；回读后按固定索引顺序用 CPU f64 累加求均值。任何非有限样本使本次统计 unavailable，不静默删除坏样本再改变分母。CPU 路径复用同一索引表和归一化，GPU 不读取陈旧 CPU flock.boids。

不修改物理力学 shader；真实 GPU readback 延迟、帧耗和 HP 长时间稳定性需另测，当前不能宣称通过。[wgpu 的映射规则](https://docs.rs/wgpu/latest/wgpu/struct.Buffer.html#mapping-buffers)仅支持这种隔离方向，实际调用服从贵方锁定版本。

声音规则：

- 鸟群数据不能授权开声或续 Show 心跳。只有本次 Show 仍有效且统一 Stop 未锁定才允许风声；唯一 sender 拥有最终 OSC session/seq/时间换算。
- empty、unavailable、原 deadline 到期或连接断开，只关闭风声，拨弦继续。不得用 energy=0 冒充关闭：现有风声此时仍有0.015底噪。我方后续增加独立风声关闭动作，优先使用已有 gate 约0.3秒释音，不重写音色。
- 同一连接短暂缺数据后，可由新鲜合法 sample 恢复风声，但不能解除统一 Stop；断线后不自动换 owner。
- Stop Show、Show 心跳失联或既有终止条件执行全局1.5秒淡出并锁定；任何新鸟群数据、新 epoch 或回调都不能复响。现有全局2秒租约/DSP失联保护保持。
