## 后续真实输入接入点（本次只读分析）

### JanVim

当前 Lua agent 的动作完成 ACK 不是实时光标轨迹；坐标中的 `byteCol0` 是 UTF-8
字节列，不是屏幕像素。不得将 ACK 或字节坐标伪装成剑客动画运动。

最低成本的后续选择是“编辑器动作节奏”：在 `nvim/lua/janvim_exhibition/actions.lua`
现有 move、insert、selection 实际应用后观察光标状态，至多 8 Hz，只保留最新采样。
对经输入队列执行的动作，应确认应用时点或使用相应光标事件，不能只在排队之后取值。
当前 `bridge-server.ts` 只接受 command/ACK，新增观测需显式协议类型及有界队列。

若要求精确跟随 JanVim 渲染后的剑客轨迹，则需要产品渲染层导出并交付新的冻结 artifact；
本候选不改产品源码、不重建 JanVim。

### 《见山》

当前 SCREEN-3 的 `show/jianshan-standby.html` 是禁用脚本和联网的安全占位画面，
没有鸟群状态。只读检查发现：

- `D:/github/JianShan`，commit `ece64ca46a18bcde4f1b5dad2f03f8f4a6ad7854`：
  Python/ModernGL 重力场程序，没有所需 OSC 鸟群导出器。
- `D:/github/JianShan02`，commit `7ba25667e61fa3bdca119cecfca729ce6b36a0da`：
  Web 和 Rust 鸟群实现，没有所需 OSC 导出器；Web 现有 density 不等同运动 energy。
  Rust GPU 路径不更新 CPU boids，不能把其旧数据称为真实 GPU 鸟群状态。

后续先确定部署仓库、版本和 CPU/GPU 路径，再导出少量聚合特征：归一化横向质心、
明确定义的平均速度能量及鸟数，至多 20 Hz；不发送逐鸟数组。
若采用已检查的 Web 版本，还需处理其现有 Tone 风声路径，避免它与 SuperCollider
同时重复出声；这属于后续真实接入，不在今晚修改范围内。

### 生命周期边界

正常诗文 reset 是非终止事件，不应映射为本原型不可恢复的 OSC `stop`。
真正停止或故障则立即停止声音；恢复后需新的声音会话并明确重新启用，不能自动恢复可听输出。
任何观测、发送或声音故障都不得阻塞视觉 cue、reset、安全占位或控制器清理。
